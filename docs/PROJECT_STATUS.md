## 1. نظرة عامة

متجر إلكتروني للملابس للسوق الجزائري، مقسوم إلى ثلاثة مستودعات مستقلة بلغة TypeScript:

| المستودع | الدور | الرابط |
|---|---|---|
| `store-api` | الخادم: قاعدة البيانات، قواعد العمل، الدفع، شركة التوصيل | https://github.com/mohachamma/store-api |
| `store-web` | واجهة الزبائن (Next.js) — عربي/فرنسي/إنجليزي | https://github.com/mohachamma/store-web |
| `store-admin` | لوحة التحكم للمدير والفريق (Next.js) — عربي/فرنسي | https://github.com/mohachamma/store-admin |

**القاعدة الذهبية (قاعدة المالك):** كل ما يظهر في المتجر يجب أن يكون قابلاً للتعديل من اللوحة. أي إضافة جديدة في الواجهة تحتاج ثلاثة أشياء: حقل في قاعدة البيانات والـ API، وعرضه في المتجر من الـ API، وصفحة تعديل في اللوحة.

**طريقة العمل:** أعدّل على فرع جانبي، ثم أفتح Pull Request فيه ملخص، ثم أدمج في `main` بعد موافقة المالك. كل دمج في `main` ينشره Vercel تلقائياً (للمتجر واللوحة). لا نستخدم GitHub Actions.

## 3. سجل العمل (الأحدث أولاً)

### 2026-11-26 — رفع الصور من الجهاز بصيغة خفيفة
**ما عملته:** عند اختيار صورة من جهازك (معرض الهاتف أو الكاميرا أو الحاسوب) تُصغَّر وتُحوَّل إلى صيغة **WebP** الخفيفة داخل متصفحك **قبل** الرفع.
- جرّبتها على صورة بحجم **12.2 ميغابايت: صارت 111 كيلوبايت** (عرض 600 بكسل). تظهر لك رسالة بالحجم قبل وبعد.
- المقاسات القصوى: الشعارات 600 بكسل، صور العروض واللافتات 1400، وصور المنتجات 1600 (عند بنائها). لا تُكبَّر الصورة الصغيرة أبداً، وتحتفظ الشعارات بخلفيتها الشفافة، وتُحفظ ملفات JPEG/WebP الصغيرة كما هي دون إعادة ضغط.
- **لا يستهلك الخادم أي معالجة** (التصغير على جهازك)، فالرفع سريع حتى على بيانات الهاتف، والموقع أسرع للزبائن.
- الـ API صار يتحقق من **محتوى الملف الحقيقي** لا من اسمه ونوعه المعلن، فلا يمر ملف خبيث بعد إعادة تسميته. ولم أعد أقبل **SVG** (لأنه قد يحمل سكربتاً)؛ للشعارات استعمل PNG أو WebP.
- في المتجر: أضفت `NEXT_PUBLIC_IMAGE_HOST` للسماح بعنوان صور R2، وتخزين الصور المحسّنة شهراً. والـ Next يخدم كل جهاز بالحجم المناسب له تلقائياً.
**ما يهمّك:** لا شيء الآن. عند إنشاء حاوية R2 ستضع اسم النطاق في `NEXT_PUBLIC_IMAGE_HOST` في Vercel الخاص بالمتجر.
**قيود:** صور GIF المتحركة تصبح ثابتة (أول إطار) عند الرفع من اللوحة.

### 2026-11-25 — الصور على Cloudflare R2
**ما عملته:** نفّذت قرارك بأن الصور تُخزَّن على Cloudflare R2 بدل Supabase.
- مسار رفع الصور في اللوحة (`POST /admin/uploads`) يرفع الآن إلى R2 مباشرة (توقيع آمن من الخادم)، ويعيد رابطاً عاماً من عنوان حاويتك. الأنواع المسموحة نفسها (PNG وJPEG وWebP وGIF وSVG) وبحد 3 ميغابايت.
- حذفت إعدادات Supabase Storage من قاعدة البيانات لأننا لا نحتاجها، وأضفت متغيرات R2 الخمسة إلى ملف الأمثلة (بلا قيم).
- أضفت 5 اختبارات (الإجمالي 61): تتأكد أن الطلب موقَّع كما يطلب R2، وأن الفشل لا يكشف تفاصيل، وأن الروابط والمسارات تُحوَّل صحيحاً.
**ما يهمّك:** لا تفعل شيئاً الآن. حين نصل إلى رفع الصور الحقيقية سأرشدك لإنشاء الحاوية وأخبرك بالقيم. وعند ربط المتجر سأسمح بعنوان صور R2 في إعدادات الصور.

### 2026-11-25 — المرحلة 3 في الـ API: المسارات العامة ومسارات المدير
**ما عملته:**
- بنيت طبقة الوصول لقاعدة البيانات بحيث تعمل بنفس الشكل على Supabase الحقيقي وعلى قاعدة تجريبية داخل الاختبارات، فصارت كل المسارات مُختبرة على قاعدة حقيقية.
- مسارات الزبائن (بدون تسجيل دخول): الصفحة الرئيسية بكل أقسامها، التشكيلة، قائمة المنتجات مع البحث بأي لغة والفلاتر (فئة، مقاس متوفر، لون، سعر) والترتيب، صفحة المنتج، المنتجات المشابهة، التخفيضات، الفئات، العلامات، نص الإعلان، الولايات وأسعار التوصيل، بلديات كل ولاية.
- النصوص تأتي بلغة الزبون مع الرجوع للعربية إن لم توجد ترجمة، والصور تأتي كروابط جاهزة.
- تسجيل الدخول عبر Supabase Auth، والتحقق من أن المستخدم مدير قبل أي مسار تحت `/admin`.
- مسارات المدير: إضافة العلامات وتعديلها وإخفاؤها وحذفها وتقديمها/تأخيرها، إعدادات شريط العلامات (الحركة والسرعة)، العروض (النصوص بثلاث لغات، الجدولة، العدّاد)، نص الإعلان، عنوان صفحة التخفيضات، ورفع الصور (حتى 3 ميغابايت، أنواع آمنة فقط).
- أضفت 28 اختباراً جديداً (الإجمالي 56) تغطي: الحماية (بدون رمز، رمز منتهٍ، رمز مزيّف، زبون عادي)، الفلاتر، منع الإدخال الخبيث، ومزامنة ما يغيّره المدير مع ما يراه الزبون.

**ما يهمّك:** كل ما تغيّره في اللوحة (علامة، عرض، نص إعلان) سيظهر في المتجر فور ربطهما بالـ API، دون أي تعديل في الكود.

## 4. قرارات تقنية (ولماذا)

| القرار | السبب |
|---|---|
| الـ API يتصل بقاعدة البيانات مباشرة (`DATABASE_URL`) ويستخدم Supabase للدخول فقط | يتيح اختبار كل مسار على قاعدة حقيقية دون مشروع Supabase. **هذا يضيف مفتاحين للمالك لاحقاً** (انظر القسم 5). الأمان نفسه: الاتصال من الخادم فقط. |
| **تصغير الصور وتحويلها إلى WebP في متصفح اللوحة قبل الرفع** | الخادم لا يعالج الصور (أرخص وأسرع)، والرفع خفيف على بيانات الهاتف، والمتجر أسرع. ولا نقبل SVG لأمان الموقع |
| **الصور على Cloudflare R2** (قرار المالك) بدل Supabase Storage | الرفع يتم من الـ API فقط عبر واجهة S3 المتوافقة، وتُعرض الصور من عنوان عام للحاوية (نطاقك أو `r2.dev`). أسماء الملفات عشوائية فتُخزَّن في ذاكرة المتصفح لسنة. |
| النصوص المترجمة تُخزَّن كـ `{ar, fr, en}` والعربية إلزامية | أي ترجمة ناقصة تعود للعربية تلقائياً |
| المبالغ أعداد صحيحة بالدينار، والخادم يعيد حساب المجاميع | لا نثق بأسعار قادمة من المتصفح |
| بيانات الزبون الشخصية تُحذف من قاعدتنا بعد تأكيد الطلب | شركة التوصيل تحتفظ بها أصلاً؛ نخفّف المسؤولية القانونية |
| الحركات بـ View Transitions الأصلية في المتصفح | سلسة وخفيفة، وتتراجع بلطف في المتصفحات القديمة |
| لا نضع أي مفتاح في الكود؛ كلها في متغيرات Vercel | حماية الأسرار |

## 7. ملاحظات ومخاطر معروفة

- **أسعار التوصيل مؤقتة** — يجب تغييرها قبل أي طلب حقيقي.
- **أسماء البلديات** من مجموعة بيانات عامة (`othmanus/algeria-cities`)؛ تُراجَع رخصتها قبل الإطلاق.
- **الحركات** اختُبرت في المتصفح الآلي فقط؛ لم أرها إطاراً بإطار، فالرأي الأخير لك على هاتفك.
- **بيانات اللوحة التجريبية** تعود لحالتها الأولى عند إعادة تشغيل الخادم إلى أن تُربط بالـ API.
- لم تُطبَّق قاعدة البيانات على Supabase بعد؛ لذلك لم تُجرَّب على الإنتاج الحقيقي (جُرّبت على Postgres محلي).
